# Development Notes

The current product is the [native Android app](../../android/README.md). The [Python Web and desktop prototype](../../web/README.md) remains available for analysis and debugging.

This directory contains earlier Python development notes. [QUICKSTART.md](QUICKSTART.md) lists its entry points; [ADDING_HEURISTIC.md](ADDING_HEURISTIC.md) describes the Python feedback rules. [CURRENT_STATUS.md](CURRENT_STATUS.md) and [NEXT_AGENT_PROMPT.md](NEXT_AGENT_PROMPT.md) are handoff snapshots from May 2026. Some commands in [TRAINING.md](TRAINING.md), [CHECKPOINTS.md](CHECKPOINTS.md), and [mvpspec.md](mvpspec.md) refer to older CLI designs.

Historical specifications and troubleshooting notes are in [`archive/`](archive/).
